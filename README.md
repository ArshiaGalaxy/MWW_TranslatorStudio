## 🤖 مترجم استودیو چیه؟

یک راه‌حل کامل و **اجراشدنی روی سیستمِ خودت** برای ترجمهٔ فارسی مانهوا (Manhwa)، مانگا و کمیک:

1. 📥 یک PDF اصلی و ترجمه‌نشده را بارگذاری می‌کنید
2. 🔍 متن همهٔ حباب‌ها به‌صورت خودکار تشخیص داده می‌شود (OCR)
3. 🌐 متن‌ها ترجمهٔ ماشینی می‌شوند (با کلید API) یا دستی تایپ می‌کنید
4. 🎨 متن انگلیسیِ داخل حباب‌ها پاک‌سازی (Inpainting) می‌شود و متن فارسی جای آن رندر می‌شود
5. 📤 خروجی نهایی، رندرشده با فونت‌های فارسی: **PDF و ZIP و PSD**

> 💡 تصویرها و دیتای شما **روی سیستم خودتون** می‌مانند (SQLite و ذخیرهٔ محلی)؛ فقط برای ترجمهٔ ماشینی از API بیرونی استفاده می‌شود (اختیاری).

## ✨ ویژگی‌ها

- 🖼 **ویرایشگر بصری**: کشیدن و جابه‌جا کردن باکس‌ها، تغییر اندازه از گوشه‌ها، تایپ ترجمهٔ فارسی با دوبارکلیک روی هر حباب
- 💎 **رابط RTL کامل**: سوییچ فارسی/انگلیسی، تم تاریک/روشن، فونت‌های Mikhak و Vazir
- 🧠 **چند سرویس ترجمه**: OpenRouter، Gemini، و Custom (هر Endpoint سازگار با OpenAI — حتی لوکال مثل LM Studio و Ollama)
- 📊 **نوار پیشرفت زنده**: لاگ لحظه‌ای برای استخراج، ترجمه و اعمال
- 📈 **OCR مخصوص مانهوا**: پشتیبانی از صفحات اسکرول‌شدهٔ عمودی، با ادغام هوشمند بین صفحه‌ها
- 📦 **خروجی چندگانه**: PDF رندرشده، ZIP صفحات WebP، فایل PSD لایه‌دار
- 🖋 **تایپوگرافی قابل تنظیم**: فونت، اندازه، رنگ، چینش، پیش‌نمایش زندهٔ هر باکس
- ⚙️ **صفحهٔ Settings**: تنظیم کلیدها، مدل‌ها، پارامترهای OCR و inpaint

## 🚀 شروع سریع: ۰ تا ۱۰۰

### راه ۱ — ویندوز، یک کلیک (ساده‌ترین)

1. 📥 پروژه را بگیرید:
   ```powershell
   git clone https://github.com/ArshiaGalaxy/MWW_TranslatorStudio.git
   cd MWW_TranslatorStudio
   ```
   (یا از صفحهٔ Releases، ZIP را دانلود و باز کنید.)
2. 🔛 فایل **`start.bat`** را دوبارکلیک کنید. بار اول، خودش این کارها را انجام می‌دهد:
   - ✔ ساخت محیط مجازی پایتون و نصب پکیج‌های پایه
   - ✔ ساخت دیتابیس (migrate)
   - ✔ نصب بسته‌های فرانت‌اند (`npm install`)
   - ✔ بالا آوردن هر دو سرور + باز شدن مرورگر

> ⏱ بار اول ۵ تا ۱۰ دقیقه (دانلود بسته‌ها)؛ از دفعهٔ دوم فقط چند ثانیه. بعدش یک میان‌بُر (Shortcut) روی دسکتاپ بسازید که همان فایل را اجرا کند.

### راه ۲ — استاندارد (لینوکس / مک / ترمینال دستی)

```bash
# 1️⃣ دانلود
git clone https://github.com/ArshiaGalaxy/MWW_TranslatorStudio.git
cd MWW_TranslatorStudio

# 2️⃣ بک‌اند — Django + API (پورت 8000)
cd backend
python3 -m venv .venv
source .venv/bin/activate                # ویندوز:  .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 127.0.0.1:8000

# 3️⃣ فرانت‌اند — Next.js (پورت 3000) — در یک ترمینال جدید
cd ../frontend
npm install
npm run dev
```

🌐 حالا مرورگر را باز کن: **http://localhost:3000** — بدون ورود (لاگین)، مستقیم وارد داشبورد می‌شوی.

### راه ۳ — استفاده از موبایل یا تبلت (همان وای‌فای لپ‌تاپ 📱)

سرورها روی لپ‌تاپ اجرا می‌شوند؛ گوشی فقط به یک مرورگر نیاز دارد:

1. ⚡ گوشی و لپ‌تاپ را به **یک وای‌فای** وصل کنید.
2. 🔛 در ویندوز فایل **`start-lan.bat`** را دوبارکلیک کنید. این اسکریپت:
   - ✔ همان سرورهای `start.bat` را بالا می‌آورد (اگر هنوز `start.bat` را اجرا نکرده‌اید، اول آن را اجرا کنید تا همه‌چیز نصب شود)
   - ✔ پورت 3000 را در فایروال ویندوز باز می‌کند (فقط بار اول)
   - ✔ آدرس مخصوص موبایل را چاپ می‌کند، مثل `http://192.168.1.42:3000`
3. 📱 همان آدرس را در مرورگر گوشی باز کنید.

> ℹ️ **چطور کار می‌کند؟** فقط فرانت‌اند Next.js (پورت 3000) روی شبکه باز می‌شود؛ بک‌اند Django روی `127.0.0.1:8000` لپ‌تاپ می‌ماند و درخواست‌های `/api` و `/media` از طریق همان پراکسی Next.js پاس داده می‌شوند — پس نیازی به تنظیم CORS یا `ALLOWED_HOSTS` نیست.
>
> ⚠️ **نکتهٔ امنیتی:** استودیو لایهٔ لاگین سمت سرور ندارد — **هر کس** روی همان وای‌فای می‌تواند بازش کند. فقط در وای‌فای خانگی/شخصی استفاده کنید، نه هات‌اسپات عمومی.
>
> 🪧 اگر گوشی به لپ‌تاپ وصل نشد، جدول عیب‌یابی پایین را ببینید (مقصر اصلی «جداسازی کلاینت» / Client Isolation در شبکه‌های مهمان است).
>
> 🖥 **لینوکس/مک:** اسکریپت لانچر وجود ندارد ولی کار ساده است: فرانت‌اند را با `npm run dev -- -H 0.0.0.0` اجرا کنید (به‌جای `npm run dev`) و در گوشی `http://<آی‌پی-لپ‌تاپ>:3000` را باز کنید (آی‌پی در لینوکس: `hostname -I`، در مک: `ipconfig getifaddr en0`).

## 🎬 ۰ تا ۱۰۰: اولین پروژه‌ات — ترجمهٔ واقعی

| مرحله                       | چی می‌شود |
|-----------------------------| --- |
| 1️⃣ پروژه ها                |
| 2️⃣ پروژهٔ جدید             | داشبورد → PDF را بکش و رها کن (drop)، نوع را **Manhwa/مانهوا** یا **Manga/مانگا** بز، پروژه بساز |
| 3️⃣ استخراج                 | دکمهٔ **Extract OCR** را بزن — حباب‌ها به‌مرور تشخیص داده می‌شوند؛ می‌توانی کاورها و صفحات اضافی را از تیک درآوری |
| 4️⃣ استودیو                 | وارد استودیو شو: باکس‌ها را جابه‌جا کن، اندازه بده، **دوبارکلیک = تایپ ترجمهٔ فارسی**؛ در پنل راست: فونت، اندازه، رنگ و چینش هر باکس |
| 5️⃣ ترجمهٔ خودکار (اختیاری) | دکمهٔ **Auto-translate** برای یک صفحه یا کل صفحات → ترجمهٔ ماشینی با API |
| 6️⃣ اعمال و خروجی           | **Apply & Export** → حذف متن اصلی و رندر فارسی → لینک **PDF / ZIP / PSD** |
| 7️⃣ تنظیمات                 | صفحهٔ Settings: کلیدها، مدل، پارامترهای OCR، استایل حروف و افکت‌ها |

> 📌 **بدون** پکیج‌های سنگین AI هم پروژه بالا می‌آید: می‌توانید دستی ترجمه بکنید و PDF/ZIP/PSD بگیرید. برای OCR خودکار و ترجمهٔ ماشینی فقط یک مرحلهٔ اضافی لازم است 👇

## 🤖 فعال‌سازی هوش مصنوعی (اختیاری)

**نصب لایه‌ای:** تا این‌جا فقط بسته‌های Core (سبک) نصب شده‌اند. برای قابلیت‌های هوش مصنوعی، بستهٔ کامل را نصب کن:

```powershell
cd backend
pip install -r requirements.txt
```

بعدش:

- 🔑 **کلید ترجمه** — از یکی از این دو راه تنظیم کن:
  - متغیر سیستم‌عامل: `setx GEMINI_API_KEY "..."` یا `setx OPENROUTER_API_KEY "sk-or-..."`
  - یا صفحهٔ **Settings** خودِ برنامه → بخش Translator

  <sub>(اگر متغیر محیطی را تازه ست کردی، سرور بک‌اند را یک‌بار ببند و دوباره اجرا کن تا خوانده شود.)</sub>

- 🎨 **Inpainting حرفه‌ای (اختیاری)** — برای پاک‌سازی باکیفیت‌تر با LaMa کافی است پکیج زیر را داخل venv نصب کنید (به‌طور خودکار شناسایی و استفاده می‌شود):
  `pip install simple-lama-inpainting`

| سطح | چه دارد؟ |
| --- | --- |
| 🧱 Core (پیش‌فرض) | سرور، ورود، ویرایش دستی در استودیو، خروجی PDF/ZIP/PSD |
| 🤖 Full (`requirements.txt`) | + OCR خودکار، ترجمهٔ ماشینی، inpainting |

## 🔑 متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `OPENROUTER_API_KEY` | — | کلید OpenRouter |
| `GEMINI_API_KEY` | — | کلید Gemini |
| `CUSTOM_BASE_URL` | — | آدرس پایهٔ سرویس سفارشی (OpenAI-compatible) |
| `CUSTOM_API_KEY` | — | کلید سرویس سفارشی (اختیاری) |
| `DJANGO_DEBUG` | `1` | در حالت `0` حتماً `DJANGO_SECRET_KEY` را تنظیم کنید |
| `DJANGO_SECRET_KEY` | — | کلید مخفی Django (برای production لازم) |
| `DJANGO_ALLOWED_HOSTS` | — | (اختیاری) لیست دامنه‌ها در production |
| `BACKEND_URL` | `http://127.0.0.1:8000` | مقصد پراکسی `/api` و `/media` در فرانت‌اند |

## 🧯 عیب‌یابی رایج

| مشکل | راه‌حل |
| --- | --- |
| `Port 8000 already in use` | پنجرهٔ سرور قبلی را ببندید، یا در cmd: `netstat -ano \| findstr :8000` و بعد `taskkill /PID <شماره> /F` |
| مرورگر باز شد ولی صفحه خطا یا خالی بود | سرور هنوز کامل بالا نیامده — چند ثانیه صبر کن و صفحه را رفرش کن |
| دکمهٔ Extract خطا می‌دهد | در محیط مجازی، `pip install -r requirements.txt` را اجرا کن — موتور OCR سنگین است و جداگانه نصب می‌شود |
| ترجمهٔ خودکار اجرا نمی‌شود | کلید API را تنظیم کن (بخش بالا) و سرور بک‌اند را ری‌استارت کن |
| `DLL load failed` روی paddleocr | Python را ۶۴-بیت (x64) نصب کن، نه ۳۲-بیت |
| صفحهٔ اول خیلی کند لود می‌شود | بار اول، فرانت‌اند در حال بیلد Next است — از دفعهٔ بعد سریع می‌شود |
| عکس‌ها/فایل‌ها دانلود نمی‌شوند | در حالت `DJANGO_DEBUG=0` فایل‌های `/media` فقط به کاربران واردشده سرو می‌شوند — مطمئن شو لاگین هستی |
| گوشی آدرس LAN را باز نمی‌کند | هر دو دستگاه باید روی یک وای‌فای **بدون Client Isolation** باشند (شبکه‌های مهمان معمولاً دستگاه‌ها را از هم جدا می‌کنند)؛ فایروال باید TCP 3000 را اجازه بدهد (`start-lan.bat` قانونش را اضافه می‌کند — ولی فقط برای شبکه‌های *Private*؛ اگر وای‌فای در ویندوز *Public* است، از Settings → Network & Internet آن را Private کنید)؛ از `ipconfig` دقیقاً **IPv4 Address** رابط وای‌فای را بردارید (نه آدرس `169.254.x.x`) |
